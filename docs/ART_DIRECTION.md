# Art Direction

## Target
Premium illustrated 2D dark-fantasy RPG, not pixel art and not 3D realism.

## Palette
- Void: #090A0D
- Surface: #15171D
- Raised surface: #20232B
- Antique gold: #C5A15B
- Muted gold: #8E7444
- Blood accent: #A33C46
- Main text: #E8E2D7
- Secondary text: #A7A19A

## Visual principles
- Strong silhouettes and readable focal points.
- Controlled highlights; avoid excessive glow.
- Painted environments with atmospheric depth.
- Characters should have consistent proportions and recognizable details.
- UI should feel like a premium fantasy game interface, not a generic admin dashboard.
- Keep gameplay information legible over artwork.

## Asset production
Create separate source assets for:
- character portraits,
- full-body character illustrations,
- battle sprites or animation rigs,
- monster art and animation rigs,
- location backgrounds,
- item and skill icons,
- combat effects,
- UI ornaments and panels.

A concept illustration is not automatically a usable sprite sheet. Define dimensions,
transparent backgrounds, animation states, and export formats before implementation.
